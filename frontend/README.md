# Swarmtest Frontend

Landing page and interactive multi-agent testing dashboard for Swarmtest.

## Features

- **Interactive Swarm Configuration**: Configure normal buyer and adversary ratios, budget caps, and seeds.
- **Dynamic Swarmtest YAML Generator**: Real-time YAML preview and export for the CLI runner.
- **Live Metrics & Inspection**: Visual overview of emergent bug detection, oversight guardrails, and role specifications.
- **Responsive Design**: Built with Tailwind CSS and Framer Motion.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Framer Motion (`motion`)

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
npm install
```

### Development

Run the local Vite dev server:

```bash
npm run dev
```

The app will be available at `http://localhost:3000`.

### Build

Compile TypeScript and build the production bundle:

```bash
npm run build
```
