## Scope and ownership

Dev3 owns `detect/`, `verify/`, `bench/`, `memory/`, their documentation, and this handoff.
Dev1 supplies Bazaar, its OpenAPI specification, invariant SQL and a disposable
reset fixture. Dev2 supplies agent execution, concurrency groups and event writes.
Neither teammate's modules are scaffolded here. Packaging files are bootstrap
files because the remote repository has no commits yet.

## Interfaces

Versioned Pydantic models describe events, findings, replay requests, concurrent
steps and verification outcomes. Events retain request inputs, sequence numbers,
concurrent groups, response hashes and costs needed for evidence and replay.
The event store is append-only with SQLite for local development and a Postgres
implementation for integration. SQL invariants return rows when violated.
Application invariant queries use read-only connections supplied by Dev1.

Detectors convert invariant failures and HTTP/transport errors into unverified
findings with event references. Replay resets an explicitly disposable target,
executes recorded steps without LLM calls, preserves concurrent action groups,
then evaluates the original oracle. Replay errors remain unverified, and an
HTTP error alone cannot verify a business invariant. Database race reproduction
is measured over repeated attempts, never guaranteed merely by a seed.

Reports export stable JSON and Markdown. Benchmark utilities score isolated and
swarm runs with equal budgets and held-out seeds, count unique verified bug IDs,
and retain raw per-run data. They do not fabricate experiments before Bazaar
and the runtime exist. A local MemoryStore persists verified findings and
classifies later successful replay checks as fixed, still failing or regressed;
failed verification attempts remain inconclusive. The Meko adapter is Dev2's
Phase 2 implementation behind the same interface.

## Alternatives and trade-offs

Rust and a mixed-language core were considered. Python follows the PRD and
reduces cross-language interface work within the 24-hour deadline. SQLite makes
isolated local runs cheap; Postgres is used for real multi-user database integration.
This change does not provision infrastructure or implement the target app.
